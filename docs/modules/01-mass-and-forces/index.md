# Module 1: Mass and external forces

## By the end, you will be able to

- Set up gravity and a 240 Hz physics tick.
- Measure free fall in PyBullet.
- Calculate and apply the upward force required for hover.

## Lessons

1. Initialize the PyBullet sandbox with gravity `(0, 0, -9.81)`.
2. Spawn a body, measure its velocity, and verify gravitational acceleration.
3. Apply an upward external force to counter gravity and create equilibrium.

Prerequisite: [Module 0: PyBullet setup](../00-pybullet-setup/index.md). Next: [Module 2: URDF engine](../02-urdf-engine/index.md).
