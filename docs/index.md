# Drone Physics & Simulation

Build a quadcopter simulator from first principles with PyBullet and Python.
The course moves from PyBullet setup and rigid-body dynamics to a stable
autonomous takeoff and hover, without relying on a flight-controller simulator.

## Course target

By the end, you will be able to model a quadcopter's frame, motors,
aerodynamics, controller, and battery in PyBullet; then connect a high-level
decision model to safe motor commands for an autonomous 5 m hover.

## Who it is for

Software engineers, robotics learners, and students comfortable with Python
and basic algebra. Familiarity with vectors and simple control loops helps,
but the course introduces each physics concept as it is needed.

Start with [Module 0: PyBullet setup](modules/00-pybullet-setup/index.md),
then use the [roadmap](roadmap.md) and [syllabus](syllabus.md) as guides.
